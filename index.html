Weighted Densest Subgraph Search

Explore an undirected, non-negative weighted graph using the greedy peeling algorithm. Enter or upload an adjacency matrix and inspect the densest state encountered during peeling.

Developed by Dr. Michael Ho

1. Adjacency matrix

Paste a square symmetric matrix. Values may be separated by spaces, tabs or commas. The diagonal must be zero. Alternatively, upload a CSV or TXT file. Uploaded matrices are processed directly and are not inserted into the text editor.

Matrix parsing, validation and greedy peeling are performed in a background worker so that the interface remains responsive during computation.

Method

For a vertex set S, this page uses weighted density

ρ(S) = W(S) / |S|

where W(S) is the sum of internal edge weights, counted once per undirected edge.

At each iteration, the vertex with the smallest current weighted degree is removed. If there is a tie, the smallest original vertex index is removed first.

The application records the density after every peeling step and reports the intermediate state with the highest weighted density.

Greedy peeling is an approximation procedure. The reported result is the highest-density state encountered during the peeling sequence, not a certificate of the global optimum.
