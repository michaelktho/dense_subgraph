Exact Weighted Densest Subgraph Search

Find globally optimal dense vertex-induced subgraphs of undirected, non-negative weighted graphs. Choose unrestricted densest-subgraph optimisation or a fixed-size densest-k-subgraph search, and inspect the solution and its optimality status.

Developed by Dr. Michael Ho
Greedy Peeling Exact Optimisation

1. Adjacency matrix

Paste a square symmetric matrix. Values may be separated by spaces, tabs or commas. The diagonal must be zero. Alternatively, upload a CSV or TXT file. Uploaded matrices are processed directly without being inserted into the text editor.

2. Optimisation problem

If time expires, the best feasible solution is reported without claiming global optimality. Fixed-size optimisation is computationally difficult for large graphs.

Validation and computation run in a Web Worker to keep the interface responsive. The unrestricted method gives a numerical optimality certificate; fixed-size search certifies optimality only if all necessary branches have been resolved.

4. Optimisation details

Method

For a vertex set S, this page uses weighted density

ρ(S) = W(S) / |S|

where W(S) is the sum of internal edge weights, counted once per undirected edge.

Unrestricted problem: maximise ρ(S) over all non-empty vertex sets. A sequence of minimum cuts determines whether a denser vertex set exists and provides an optimality certificate.

Fixed-size problem: maximise W(S) subject to |S| = k. A branch-and-bound search uses valid upper bounds to eliminate subsets that cannot improve the incumbent. It is an exact search method when completed, but is not an external MILP solver.

The underlying objective agrees with the greedy peeling webpage. An exact result can therefore be used to evaluate a greedy approximation on the same input.
